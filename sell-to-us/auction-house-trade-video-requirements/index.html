Auction House Trade Video Requirements

If an order is completed through the Auction House, the recording should make it possible to verify the listed item, matching price, seller ID, purchased item details, selected ruleset and Battle.net account region.

Recording principle
Keep each step visible and in sequence. The listing and seller identity must be checked before purchase, and the mailbox evidence should correspond to the item and amount in the order.
01
Find the listed item

Locate the item in the Auction House

Open the Auction House, search for the exact item name and expand the list of available auction listings for that item.

Check: The item name and its available auction listings are clearly visible.
02
Verify seller and price

Confirm the listing price and seller ID before buying

Find the auction listing whose sale price matches the order amount. Hover the mouse pointer over that listing to view the seller ID. If multiple listings have the same price, carefully verify the seller ID before purchasing to make sure you select the correct listing.

Check: The selected listing has the correct order price and the seller ID is verified before the purchase.
03
Check the mailbox evidence

Open the Auction House mail and verify the details

Go to the mailbox and open the message. Check the item name, item quantity, item price/amount and the in-game ID of the character that listed the item for sale.

Check: The mail displays the correct item name, quantity, transaction amount and listing character's in-game ID.
04
Verify the ruleset

Return to the character-selection screen

Log out to the character-selection screen. Open the Ruleset selector and confirm that the selected ruleset is the one specified in the order.

Check: The ruleset shown on the character-selection screen matches the order.
05
Verify the account region

Show the Battle.net client region

Switch to the Battle.net client and show the account region displayed in the upper-right corner. Confirm that it matches the game region specified in the order.

Check: The region shown in the upper-right corner of the Battle.net client matches the order's game region.

Quick recording checklist

  • Search for the exact item name and expand the auction listings.
  • Choose the listing with the order-matching price.
  • Hover over the listing and verify the seller ID; if prices are identical, confirm the ID before buying.
  • Open the mailbox and show item name, quantity, price/amount and listing character ID.
  • Return to character selection and show the correct ruleset.
  • Show the Battle.net account region in the upper-right corner and confirm it matches the order.
