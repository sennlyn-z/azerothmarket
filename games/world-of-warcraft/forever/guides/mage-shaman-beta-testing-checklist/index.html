Mage and Shaman Beta Testing Checklist for WoW Forever

Use this source-first checklist to evaluate the Mage and Shaman changes described by Blizzard without treating beta tuning as final.

1. Mage: test the spell-school identity

  • Frost: record control value, safe soloing, and how reliably spells create space.
  • Fire: test critical-strike setups and note how much preparation they require.
  • Arcane: evaluate how Arcane tools amplify your wider toolkit and how resource pressure affects longer fights.
  • Try a mixed-school talent setup if available, but compare it with a focused build rather than assuming one is best.

2. Shaman: measure setup and utility

  • Check how longer-lasting weapon imbues and totems change the number of refreshes needed during a typical session.
  • Test totem tracking and placement in a group, including whether party movement makes a placement inconvenient.
  • Try Call spells, Totemic Recall, and Totemic Projection where available; note convenience separately from combat effectiveness.
  • Record mana costs, cooldowns, and group utility at the same level to make comparisons useful.

3. Keep a useful test log

For each build, note beta build/date, level, talents, weapon, gear, target type, party size, fight length, and any observed bug. Compare like with like; a level or gear difference can make damage numbers misleading.

4. Avoid common mistakes

  • Do not treat one beta build as final launch balance.
  • Do not copy a build from another WoW version without checking Forever-specific spell and talent behavior.
  • Separate a confirmed patch note from a player's interpretation of whether a change is a buff or nerf.

Source: Blizzard — Mage and Shaman class deep dive, October 7, 2026.
