WoW Forever Gamepad Setup Guide: Controls and Compatibility

Blizzard has published a controller guide for Forever. Use this overview to understand compatibility and test core actions without assuming every setup behaves identically.

Compatibility note: Blizzard's published guide identifies XInput support and Xbox/PlayStation button prompts. Check the official guide and your current client version for the latest supported devices and instructions.

Core controller actions to test

  • Targeting: test enemy and friendly target selection in a safe area.
  • Casting: confirm your action bar mapping and verify spells with different target requirements.
  • Looting and interaction: test interacting with objects, NPCs and defeated enemies.
  • Menu navigation: check character, settings and inventory screens.

Setup checklist

  1. Connect a supported controller before launching or returning to the game.
  2. Confirm the controller is recognized by the operating system and client.
  3. Review the game's controller options and button prompts.
  4. Test movement, targeting, one instant ability, one cast-time ability and interaction.
  5. Adjust bindings to fit your class and comfort. Re-test after any changes.

Common troubleshooting approach

If input is not recognized, verify the controller connection and XInput compatibility, then restart the client if needed. If prompts differ from your device, consult Blizzard's official documentation and support guidance rather than assuming a binding.

Controller support can evolve after launch. This guide is an orientation checklist, not a complete mapping for every controller or class.
