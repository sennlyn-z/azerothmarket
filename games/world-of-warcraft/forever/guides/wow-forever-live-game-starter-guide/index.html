WoW Forever Live Game Starter Guide: Classic vs Enhanced

A quick orientation for new players: understand visual presets, make a character, tune the interface, and verify important details in the live client.

Start with your preferred experience: Blizzard's launch guidance describes Classic and Enhanced visual presets, along with options for HD/SD models and interface customization. These choices primarily help you shape presentation and comfort; inspect the current client settings for exact options.

1. Classic or Enhanced?

  • Classic: choose this if you prefer a more original-era presentation and familiar visual style.
  • Enhanced: choose this if you prefer updated visual presentation. It is a preset, not an indication of character power.
  • Model and interface options: explore the available HD/SD model and UI options in settings. Names and availability may vary by client version.

2. Character creation checklist

  1. Select the Ruleset you intend to play.
  2. Choose race and class based on the role and playstyle you want to learn.
  3. Review the character's full name and appearance before confirming.
  4. Keep in mind that class balance and ability details can receive tuning.

3. Interface and comfort

  • Adjust UI scale, readability and audio to comfortable levels.
  • Review keybindings before entering difficult group content.
  • Try the available targeting and interaction settings in a safe area.
  • Use the official gamepad guide if you want to play with a controller.

4. Be careful with beta-era information

Some older AzerothMarket pages are retained as historical beta records. A beta value or observation may not match the launch build. Prefer pages marked live-game updated and consult official notes for changes.

The client is the authority for the options currently available to your account and region. This guide intentionally avoids asserting specific performance gains or unsupported setting details.

Official reference: World of Warcraft official site and launch articles.
