WoW Forever Dungeons: XP, Deserter and Beta Changes to Watch

A dated guide to tracking dungeon progression changes while community discussion and beta testing continue.

Dungeon progression is still being discussed

Recent Blizzard forum discussion includes feedback about dungeon XP, leveling speed and the dungeon deserter system. These discussions should be treated as player feedback unless Blizzard confirms a mechanical change.

How to document dungeon changes

  • Record the dungeon name and character level.
  • Separate normal observations from official patch notes.
  • Track XP changes by dated build rather than one permanent number.
  • Connect bosses and loot to the dungeon record.

Blizzard's September 24 known-issues update also documented fixes and unresolved interface issues, showing why dungeon and combat information should remain version-aware during beta.
